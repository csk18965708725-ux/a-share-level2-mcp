# 网盘压缩包提取器：公开使用说明

适用版本：**v1.1.0**

这套工具用于从百度网盘历史数据压缩包中，按 **日期 / 股票代码 / 文件名** 提取目标文件，避免先下载整个压缩包。

## 使用前准备

- Windows 电脑
- Microsoft Edge
- 已登录的百度网盘账号
- 百度账号本身具备在线解压权限
- 已完成软件正常安装与授权

> 本公开文档不披露授权机制、激活实现、账号信息或内部逻辑。

## 基本安装流程

1. 安装“网盘压缩包提取器”。
2. 在 Edge 打开 edge://extensions/。
3. 开启“开发人员模式”。
4. 选择“加载解压缩的扩展”，加载安装目录下的 extension 文件夹。
5. 确认扩展已启用。
6. 在同一个 Edge 浏览器中登录百度网盘，并在执行任务时保持网页已登录。

## 填写提取规则

实际说明中给出的精确提取示例：

~~~text
日期：20170619
股票匹配：精确
股票代码：000001
文件匹配：精确
文件名：行情.csv
~~~

然后：

~~~text
填写规则 → 校验计划 → 开始执行
~~~

要换数据类型，只需把目标文件改成 逐笔委托.csv 或 逐笔成交.csv。

工具说明中还明确支持多条规则和 Excel 模板批量执行。

## 目录示例

~~~text
/逐笔十档tick数据(17-23)/
└─ 2017/
   └─ 201706/
      └─ 20170619.7z
         └─ 20170619/
            ├─ 000001.SZ/
            │  ├─ 行情.csv
            │  ├─ 逐笔委托.csv
            │  └─ 逐笔成交.csv
            └─ ...
~~~

17-23 是已实测历史目录名，不代表数据只到 2023。

## 常见问题

### file value is required for exact

表示某条规则选择了“文件精确匹配”，但文件名实际为空。输入框里的灰色 行情.csv 可能只是占位提示，需要手动输入真实文件名后重新校验。

### 一直等待 / 没反应

依次检查：

- Edge 中是否已经登录百度网盘
- 百度网盘网页是否保持打开
- edge://extensions/ 中扩展是否启用
- 刚安装或更新扩展后是否刷新过百度网盘网页
- 百度账号是否具备在线解压权限

## 日常使用

~~~text
打开软件 → 保持百度网盘登录 → 填规则 → 校验计划 → 开始执行
~~~
