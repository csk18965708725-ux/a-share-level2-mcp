## 使用时需要注意

1. 字段以原始文件实际列名为准，不同市场、年份和证券类别可能有差异。
2. 某些价格或数值字段可能采用整数缩放存储，正式研究前应按实际数据口径确认缩放关系。
3. 集合竞价、连续竞价和收盘阶段的字段表现可能不同。
4. 本仓库只是结构样本，不等于完整数据字典，也不对原始字段做超出材料范围的主观解释。
