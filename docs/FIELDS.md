### 行情快照频率

- 连续竞价阶段的十档盘口快照约 **3 秒一笔**。产品实测样本中，`600519.SH / 2026-06-12` 共 4,998 笔快照，相邻间隔绝大多数为 3.0 秒。
- 集合竞价阶段快照频率更低，实测约 **9 秒一笔**；9:25 撮合时会出现开盘撮合价。
- **不要把快照频率和逐笔事件精度混在一起**：逐笔委托/成交是一笔一条事件流，时间字段实际精度为 10 毫秒。

## 沪深两市需要特别注意

**撤单口径不同：**

- 沪市撤单出现在 **逐笔委托** 表，`委托类型 = D`；
- 深市撤单出现在 **逐笔成交** 表，`成交代码 = C`。

只按单一市场口径处理，会导致另一市场的委托簿重建发生系统性偏差。

**逐笔委托历史起点也不同：**

- 深市：2017 年起三张表均有；
- 沪市：逐笔委托从 **2021-07-26** 起提供；此前沪市只有十档快照和逐笔成交。

## 文件格式注意事项

- 原始 CSV 编码：**GB18030**；
- 三张 CSV 表头末尾都有一个多余空字段，因此 pandas 读取时可能出现 `Unnamed` 列，可按需删除；
- 股票的 IOPV、指数统计类字段为 0 并不代表数据缺失，而是该字段不适用于普通股票；
- 字段及枚举最终以具体交易所、证券类别和实际文件为准。

## English summary

- Quote snapshots contain **66 columns**, including 10 ask levels and 10 bid levels with sizes.
- All price fields are stored as integers in **1/10,000 CNY** units.
- Tick-order and tick-trade timestamps use `HHMMSSmmm`, with **10 ms actual precision**.
- Continuous-auction quote snapshots are approximately **3 seconds apart**; tick orders/trades are event streams.
- Shanghai and Shenzhen use different cancellation locations/codes, which matters when rebuilding an order book.
